# Portfolio Migration & Trust Rules

## Reframe old work

| Old Type | New Category |
|---|---|
| Corporate/documentation websites | Digital Systems |
| Node/Django/Firebase work | Digital Systems / Lab Experience |
| Remote research/project assistance | Remote Technical Operations |
| Business proposals | B2B Enablement |
| Tender work | Tender Documentation Support |
| Technical product deployment | Product Launch Support |
| B2B/project sales activity | Business Enablement Experience |
| Project coordination/handover | Technical Project Support |
| Sensor/device work | Technical Project Support |
| Surveillance layouts | Technical Project Support |
| Device troubleshooting | Managed IT & Technical |
| Social/video/banner work | Additional Capabilities |

## Status labels
Use only:
- PK-TANK Project
- Founder’s Past Experience
- Prototype
- Internal Product
- Demonstration
- Research / Lab Project

## Trust rules
Do not automatically migrate:
- testimonials
- corporate logos
- client names
- confidential PDFs
- private project drawings
- personal contact data

Only publish evidence-backed claims.

Do not invent:
- client counts
- project counts
- revenue
- percentages
- years
- testimonials

For engineering work, never imply licensed engineering approval/certification unless actually authorized.
